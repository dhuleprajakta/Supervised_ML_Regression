# Supervised_ML_Regression
This repository contains Supervised ML Regression projects 📈 that focus on predicting continuous values using labeled data 🔢. It includes models like Linear Regression, Ridge, Lasso, and Polynomial Regression, applied to real-world problems like price and salary prediction 💰.


# 📈 Supervised ML - Regression Projects

This repository contains **Supervised Machine Learning** projects focused on **Regression**, used to predict continuous values from labeled data 🔢.

## 🚀 Techniques Used

- 📊 **Linear Regression**  
- 📉 **Ridge & Lasso Regression**  
- 🌀 **Polynomial Regression**

## 📂 Projects Included

- 🚗 **Car Price Prediction** – Estimate used car value based on features.  
- 🏥 **Medical Insurance Cost** – Predict insurance charges based on age, BMI, and habits.  
- ✈️ **Flight Fare Prediction** – Forecast flight ticket prices using travel details.  
- 🏠 **Property Price Prediction** – Estimate house value from size, location, and amenities.  
- 🚕 **Taxi Price Prediction** – Predict taxi fare using distance, duration, and location data.

---

📌 These regression projects help build models that forecast real-world numerical outcomes, assisting in smarter decision-making.
